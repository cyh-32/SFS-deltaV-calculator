# 🚀 SFS火箭 Delta-V 计算器(真实模式)

一个**零依赖、单文件 HTML** 的多级火箭 Δv 计算工具。打开即用，无需构建、无需服务器。

采用齐奥尔科夫斯基火箭方程，支持多级火箭设计、**并联助推器**、实时重算、**严格物理质量链校验**，并提供三套经过联网核对的真实火箭预设数据。

## ✨ 功能特性

- **齐奥尔科夫斯基公式**：`Δv = Isp × 9.81 × ln(湿重 / 干重)`
- **多级火箭设计**：点击「＋ 添加一级」动态增加级数，每张级卡片可单独删除
- **并联助推器**：点击「＋ 添加助推器」为火箭配置多个助推器（橙色卡片区分），支持随时增删；助推器与第一级同时点火，先耗尽者分离后第一级继续工作
- **每级推力输入**：每一级卡片新增「推力（kN）」输入框，用于助推器组合计算
- **实时计算**：任意输入框变化即自动重算各级 Δv、助推器阶段与总 Δv，无需提交按钮
- **严格质量链约束**：校验 `上一级干重 > 下一级湿重`，违反时该级红框报错、总结果失效
- **三套模式预设**（真实数据）：
  - 🛰️ **简单模式 · Falcon 9**（两级，无助推器）→ 理想总 Δv ≈ **9,255 m/s**
  - 🌕 **困难模式 · Saturn V**（三级，无助推器）→ 理想总 Δv ≈ **13,795 m/s**
  - 🚀 **助推器模式 · Ariane 5 ECA**（两级 + 2 枚固体助推器）→ 理想总 Δv ≈ **14,335 m/s**
- **任务参考提示**：按总 Δv 给出入轨/深空任务评估
- **深空极客视觉**：纯黑背景 `#0B0E14`、霓虹青 `#00E5FF`、橙色助推器卡片 `#FF8C00`、毛玻璃卡片、等宽发光大字

## 🧭 质量口径说明

工具采用「**点火时总质量**」的物理严格口径：

- **湿重** = 该级点火时整枚火箭剩余总质量（含上面级与载荷）
- **干重** = 该级燃尽分离后、下一级点火前的剩余质量
- **助推器湿重 / 干重** = 助推器自身含燃料质量 / 空重（不包含在级湿重内）

因此必须满足 **上一级干重 > 下一级湿重**，否则质量不守恒，总 Δv 判定失效。

## 🔥 助推器计算逻辑（并联）

当存在助推器时，所有助推器与**第一级（最下面一级）**同时点火，按以下顺序计算：

1. 总推力 `F_total = Σ助推器推力 + 第一级推力`
2. 总质量流量 `ṁ_total = Σ(推力ᵢ / (比冲ᵢ × 9.81)) + 第一级推力 / (第一级比冲 × 9.81)`
3. 组合比冲 `Isp_comb = F_total / (ṁ_total × 9.81)`
4. 各助推器燃烧时间 `t = (湿重 − 干重) / (推力 / (比冲 × 9.81))`，取 **最小值** `t_b` 作为分离时刻
5. 第一阶段 Δv（助推器 + 第一级）：
   `Δv₁ = Isp_comb × 9.81 × ln(总起飞质量 / 分离质量)`
   - 总起飞质量 = 第一级湿重 + Σ助推器湿重（第一级湿重已含上面级）
   - 分离质量 = 总起飞质量 − (Σ助推器燃料质量 + 第一级在 t_b 内消耗的燃料)
6. 第一级剩余燃料 = 第一级湿重 − 第一级干重 − 第一级消耗；若为负 → 报错「助推器工作时间过长，第一级燃料不足」，总结果失效
7. 第二阶段 Δv（第一级单独工作）：
   `Δv₂ = 第一级比冲 × 9.81 × ln(起始质量 / 结束质量)`
   - 起始质量 = 分离质量 − Σ助推器干重；结束质量 = 起始质量 − 第一级剩余燃料
8. 后续各级（第二级、第三级……）仍按串行公式依次累加
9. 总 Δv = Δv₁ + Δv₂ + 后续各级 Δv

> 没有任何助推器时，完全退回纯串行计算，行为与旧版一致；此时各级推力输入不影响结果。
